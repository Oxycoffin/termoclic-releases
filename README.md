# Termoclic: versiones

Aquí solo se publican las versiones compiladas y firmadas de Termoclic (registro de temperaturas de farmacia), para su actualización automática. El código no es público.

Cada versión incluye `latest.toml`, con la huella SHA-256 y la firma Ed25519 de cada ejecutable. La aplicación solo instala archivos cuya firma verifica con la clave pública que lleva dentro.
